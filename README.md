# 🥪 Hora del Bocata – Aventura Gráfica en Pixel Art

## 🎮 Descripción del Proyecto

*Hora del Bocata* es una aventura gráfica web con estética pixel art de 16 bits y vista top-down. Inspirado en el episodio "La Hora del Bocata" de la serie *Hora de Aventuras*, el juego ofrece una experiencia cozy donde el jugador explora un mundo acogedor, interactúa con personajes no jugables (NPCs) y recolecta ingredientes para preparar el bocadillo perfecto.

## 🧠 Contexto y Motivación

La idea surge de nuestra pasión por los videojuegos, *Hora de Aventuras* y las aventuras gráficas de estilo cozy. Aunque existen juegos basados en la serie, la mayoría son de plataformas, lucha o investigación. Con este proyecto, buscamos explorar otros frameworks y adentrarnos en el desarrollo de videojuegos, creando una experiencia que nos gustaría jugar y en la que creemos firmemente.

## 🎯 Objetivos

* Explorar y aprender nuevos frameworks y herramientas de desarrollo de videojuegos.
* Desarrollar una aventura gráfica web con estética cozy.
* Implementar gráficos pixel art de 16 bits dibujados por nosotras.
* Aplicar metodologías ágiles, específicamente **Scrum**, para gestionar el proyecto de forma estructurada y eficiente.
* Fomentar el trabajo en equipo, distribuyendo tareas y responsabilidades para lograr una colaboración fluida y organizada.

## 🧩 Características Principales

* **Estilo Visual**: Pixel art de 16 bits dibujado a mano.
* **Perspectiva**: Vista top-down.
* **Jugabilidad**: Exploración, interacción con NPCs y recolección de ingredientes.
* **Plataforma**: Juego web accesible desde navegadores modernos.
* **Controles**: Pensado para jugarse en PC usando solo el teclado, ofreciendo una experiencia simple y accesible.
* **Accesibilidad**: Enfoque en una jugabilidad inclusiva y sin barreras técnicas.
* **Inspiración**: Basado en el episodio "La Hora del Bocata" de *Hora de Aventuras*.

## 🔧 Tecnologías Utilizadas

* **Lenguajes**: HTML5, CSS3, JavaScript.
* **Frameworks/Librerías**: [Phaser](https://phaser.io/), [Tiled](https://www.mapeditor.org/).
* **Herramientas de Diseño**: [PixelArt](https://www.pixilart.com/) para la creación de los personajes y [Photopea](https://www.photopea.com/) para el resto de diseños.

## 🚀 Cómo Jugar

### 🔗 Versión Web

Juega directamente desde tu navegador:

➡️ [https://horadelbocata.ieti.site/](https://horadelbocata.ieti.site/)

---

### 💻 Jugar en Local

Si prefieres ejecutar el juego en tu propio equipo, sigue estos pasos:

1. **Requisitos**: Asegúrate de tener instalado PHP u otra herramienta para levantar un servidor local (como Python o Node.js).

2. **Clona el repositorio**:
   ```bash
   git clone [https://github.com/usuario/horadelbocata.git](https://github.com/casiopea512/HoraDelBocata_ProyectoSintesis.git)
   cd HoraDelBocata_ProyectoSintesis
   ```
3. **Levanta un servidor**:
   - Usando PHP:
        ```bash
        php -S localhost:8080
        ```
    - Usando Python 3::
        ```bash
        python3 -m http.server 8080
        ```
4. Abre el juego en tu navegador:
    ```bash
    http://localhost:8080/
    ```
